# 關於 Flipside

白天，你穿梭在信件與會議之中，用名片上的頭銜介紹自己。夜晚，你練琴、打球，或者換上一個只有同好才懂的 ID 上線。

這兩個都是真實的你，卻鮮少能在同一個空間裡並存。

多數個人網站受限於單一版型與敘事方式，逼得我們總得面臨取捨：該展現專業，還是分享熱愛？最終，往往只能妥協讓其中一面代表自己。

但是，何必妥協？

宛如一枚硬幣，正面是專業，反面是熱愛。兩面皆是真實的你，只需輕輕翻轉，即可讓訪客從截然不同的視角，認識更完整的你。

這就是「Flipside」，一款設計簡潔、且對中文排版高度友善的 Astro 主題。他源自作者的個人網站，在剔除私人內容後，萃取了開發過程中累積的巧思，淬鍊成一個隨開即用的網站起點。希望幫助更多人，輕鬆打造出既能彰顯專業能力，又能盡情展現個人特色的專屬空間。
